# Changelog

- **1.3.2** (2026-11-23): Gives the exact build line with `--out .proofs/pages/<name>.html`, the one folder the optional `open` allow rule covers, so the page can be opened. A spec's asset path that is not found next to the spec is now tried from the working directory, and the error names both paths.
- **1.3.1** (2026-11-22): Says to run `--smoke` every time: if it reports Playwright missing, run the one-line install it prints (no browser download) and run it again; if it still cannot run, say on the page and in chat that the self-check did not run. It no longer reads as optional when Playwright is absent.
- **1.3.0** (2026-11-22): Runs its scripts (`review_page.py`) through `${CLAUDE_PLUGIN_ROOT}` and pre-approves them and reads of the plugin's own files, so a session no longer asks permission for each one.
- **1.2.0** (2026-11-19): The page's header now starts with the proofs mark and a `questions` pill, then the project and the session (accented), in the sticky bar with no added height. Fill `project.session`; a page without it still builds, with a warning.
- **1.1.0** (2026-11-19): Description sharpened: this skill fires whenever Claude needs the user to answer or decide anything, including several decisions to answer later or from a phone, and still supplies the questions on working-log's session page. Found by the ambiguous trigger evals, where such a request fired working-log instead.
- **1.0.1** (2026-11-19): Says plainly that it needs the whole plugin, for anyone who copies one skill folder on its own.
- **1.0.0** (2026-11-18): New skill, split out of working-log's questions-for-you mode: batched questions with real controls, a stable qid, notes, a recommended option, a Decided list and the questions export (now `[questions v1.3 — answers]`). Starts on its own the first time a session has a question for the user. New rule: open questions are the first thing on the page, directly under the sticky bar, and the builder enforces it. Works on working-log's session page or as its own page.
