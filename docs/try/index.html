Try Proofs, then tell me where you got stuck

Proofs is a free plugin for Claude Code. Instead of describing a redesign in text, Claude shows you real mockups next to your live page, you pick with buttons, and you paste your picks back. You'd be one of the first people besides me to use it, so anything that confuses you is exactly what I need to hear.

About 15 minutesYou need Claude Code installedAny web page works, even one you don't own

Four steps

  1. Install it

    In Claude Code, run these two commands:

    /plugin marketplace add https://github.com/workingBen/proofs.git /plugin install proofs@proofs

    If it asks you to restart Claude Code, do that.

  2. Ask for a design review

    Paste this, with a real web address in place of the bracket. Your own site, a work page, or any public page you think could look better:

    Use the design-review skill to propose two or three design updates for the page [YOUR URL]
  3. Open the page it gives you and decide

    Claude captures the page and builds two or three real redesigns, then gives you a link to a review page. Look at each option, press a button on each (keep, use, comment, or ask for another try), then press Copy My Decisions.

    This takes a few minutes. If you get a file instead of a link, open the file in your browser.

  4. Paste your picks back

    Paste what you copied into Claude Code. If the page is in a project you have open, Claude builds exactly what you picked. If it isn't your page, stop here; the review is the part I want feedback on.

If Claude just describes ideas in text instead of making a page, say "use the design-review skill" again. That alone is useful to tell me.

Curious about the rest? There are 12 skills; the list is at workingben.github.io/proofs.
