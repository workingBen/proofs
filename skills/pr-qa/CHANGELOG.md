# Changelog

- **1.8.0** (2026-11-22): The page lists the other open PRs it skipped, even when there are no PRs to cover, and entries without a number are left out. A rise in small text or tap targets, including repeated small labels, now holds back a merge recommendation until it is explained. The `--smoke` self-check has a timeout, it opens its saved page with exactly `open .proofs/pages/<name>.html`, which the opt-in `--project` allow block pre-approves (if `open` is refused it prints the path instead of retrying), and the call counts are true (the no-PR path counts the extra `cp .env`). House rule 4: use the helpers' own checks, not `file`, `magick` or `sed -i`.

- **1.7.5** (2026-11-22): Removes the `.proofs/base` worktree right after the before shots are taken and read, before checking out the branch or running its tests, so test runners and linters that walk the tree cannot pick up the base copy. Common Mistakes keeps the cleanup as a backstop.
- **1.7.4** (2026-11-22): The capture example sets `CHROME` inside the `sh -c` capture command instead of in front of `python3`, so the command matches the unattended allow rule for the helper.
- **1.7.3** (2026-11-22): `pr_qa_findings.py` says "not measured" instead of "clean" when the evidence holds no measurements, decided per route so a partly measured run never reads clean.
- **1.7.2** (2026-11-22): New `PROOFS_BASE_DIR` setting moves the before-shot base worktree to `$PROOFS_BASE_DIR/<repo folder name>-pr-qa-base`, for setups that block `git worktree add` inside code folders. Unset, it stays `.proofs/base`.
- **1.7.1** (2026-11-22): Names the helper's log for each run (`.proofs/base/.proofs/server.log` for the before run, `.proofs/server.log` for the after run) and which `node_modules` the before capture resolves Playwright from.
- **1.7.0** (2026-11-22): Before shots come from a worktree at `.proofs/base`, with its own installed dependencies, and every capture runs through the start-capture-stop helper.
- **1.6.0** (2026-11-22): Runs its scripts (`pr_qa_page.py`, `pr_qa_findings.py` and `pr_qa_plan.py`) through `${CLAUDE_PLUGIN_ROOT}` and pre-approves them and reads of the plugin's own files, so a session no longer asks permission for each one.
- **1.5.1** (2026-11-21): The headless Chrome command adds `--disable-features=MacAppCodeSignClone`. On a Mac, Google Chrome copies its whole app (about 1.4 GB) into a temp folder on every launch and deletes it only on a normal quit, so screenshot runs left those copies behind.
- **1.5.0** (2026-11-19): The top bar starts with the proofs mark and a `pr-qa` pill, then project · session · repo; the "PR QA" label is gone. New `--session` flag on `pr_qa_page.py`; without it the page builds and says it has no session.
- **1.4.5** (2026-11-19): Says plainly that it needs the whole plugin, for anyone who copies one skill folder on its own.
- **1.4.4** (2026-11-18): Description trimmed to the trigger and how it differs from its nearest sibling; the detail it used to carry is in the body. No change in behavior.
- **1.4.3** (2026-11-18): Moved 'Where the page goes' to a shared reference file and the changelog to CHANGELOG.md; no change in behavior.
- **1.4.2** (2026-11-17): Copy buttons now fall back to a selectable text box when the clipboard is unavailable (as on a Wi-Fi-served page), and `wifi` mode is limited to a private network you trust. The session reminder now ships as a plugin hook that stays off until `PROOFS_PR_REMINDER=1` is set (the installer sets it); no path is written into project settings. Invocations use `/proofs:pr-qa`.
- **1.4.1** (2026-11-16): New section "Where the page goes": a project can choose an artifact, a local file, or a file served on its own Wi-Fi.
- **1.4.0** — Merged into proofs: generic, no project-specific steps.
