# Changelog

- **1.12.2** (2026-11-23): House rule 2: never `ls` or Read `~/.cache/proofs-playwright` to see whether Playwright is installed (outside the project, so the call is refused); the capture and `--smoke` report a missing install themselves.

- **1.12.1** (2026-11-23): The build refuses a session-page log entry that asks: a status other than Background, Queued or Done (no more "Your move"), or a lede ending in a question mark. A free-text question once went out as a log entry, because only entries with option buttons were refused, and the reader had to find it in the log.
- **1.12.0** (2026-11-22): Opens its saved page with exactly `open .proofs/pages/<name>.html`, which the opt-in `--project` allow block pre-approves; if `open` is refused it prints the path instead of retrying. Adds house rule 4: use the helpers' own checks, never `file`, `magick`, `identify` or `sips`, and change files with Edit or Write, never `sed -i`.

- **1.11.1** (2026-11-22): Says to run `--smoke` every time: if it reports Playwright missing, run the one-line install it prints (no browser download) and run it again; if it still cannot run, say on the page and in chat that the self-check did not run. It no longer reads as optional when Playwright is absent.
- **1.11.0** (2026-11-22): Runs its scripts (`review_page.py`) through `${CLAUDE_PLUGIN_ROOT}` and pre-approves them and reads of the plugin's own files, so a session no longer asks permission for each one.
- **1.10.2** (2026-11-19): Cleanup reads a page or folder resumed from a handoff before listing it, and names any other topics it still holds, so a delete doesn't silently take another project's steps with it.
- **1.10.1** (2026-11-19): The build check fails a page whose in-page link (say "Open questions above") points at a section that is no longer on it, the stale link left after the reader answered.
- **1.10.0** (2026-11-19): The page follows session renames: it reads the session's current name before every republish and updates the title and project bar, keeping the same URL. A new section, "When the session is done", has the session keep a list of everything it creates (pages, folders, worktrees, handoff notes), ask once at the end with the whole list, and delete what the user approves, with the session page last.
- **1.9.0** (2026-11-19): A link to a spot on the same page (#questions, #checks, #log, an entry id) jumps there and says so ("Open questions above") instead of "Open it". The project bar starts with the proofs mark and a `working-log` pill, replacing the trailing "Session page" label; it adds no height, and on phones only the pill shows. Links to other pages take a `state`: `in-progress` (muted, listed after open ones, titled "Pages Claude is working on" when all are) or `open`. A pasted export now republishes the session page first: answered pages go in progress and answered questions move to Decided. Log entries take `when` (the user's local time, `2026-11-19T15:54`), shown as `Nov 19 - 3:54PM` after the title and in the export line.
- **1.8.0** (2026-11-19): Entries ticked **Read this** fold to one line under **Read** at the bottom of the log, so settled news stops taking up the page. Unread entries, and any entry with an unanswered option, keep their full card and note box; unticking brings a card back, and notes on read entries still go in the export.
- **1.7.2** (2026-11-19): Description names stepping away as a trigger and says it owns the page and the log, while the questions themselves come from the questions skill. The page still starts the first time a session has something waiting on the user. No change in behavior.
- **1.7.1** (2026-11-19): Says plainly that it needs the whole plugin, for anyone who copies one skill folder on its own.
- **1.7.0** (2026-11-18): The working log is now one session page per session (`"mode": "session"`): Waiting on you, Checks for you, Log and Decided, each shown only when it has content, with one Copy button for every section. The questions mode moved to the new `questions` skill and QA checklists to `qa-checklist`; design reviews and copy edits stay their own pages, linked from Waiting on you. The page starts on its own the first time a session has something for the user. Open questions come first, enforced by the builder; log entries no longer carry answer buttons. On phones the two top bars collapse to one line: session name, tally and Copy.
- **1.6.1** (2026-11-18): Description trimmed to the trigger and how it differs from its nearest sibling; the detail it used to carry is in the body. No change in behavior.
- **1.6.0** (2026-11-18): The log and the questions page are now built by the shared, tested builder (`shared/review_page`, log and questions modes); `questions-template.html` is replaced by example specs. Same pages and export formats; the questions copy fallback is now a selectable text box instead of a prompt dialog.
- **1.5.3** (2026-11-18): Moved 'Where the page goes' to a shared reference file and the changelog to CHANGELOG.md; no change in behavior.
- **1.5.2** (2026-11-17): Copy buttons now fall back to a selectable text box when the clipboard is unavailable (as on a Wi-Fi-served page), and `wifi` mode is limited to a private network you trust. Removed the unused COMMAND.md; invocation is `/proofs:working-log`; `artifact-design` is used if available.
- **1.5.1** (2026-11-16): New section "Where the page goes": a project can choose an artifact, a local file, or a file served on its own Wi-Fi.
- **1.5.0** (2026-11-17): Absorbed batched-decisions: a questions-for-you mode.
- **1.4.0** (2026-11-16): Merged into proofs: generic, no project-specific steps.
