# Changelog

- **1.4.10** (2026-11-24): `capture.cjs` adds two fields to `measures.json`, with no existing field changed: `sections` (each section's label, box and elements: headings, text, buttons, links, images, lists, forms and badges) and `fontSizes` (the page's own type sizes), and `summary.md` lists the sections with element counts. design-review copies them into its items to account for every element and check type sizes. A third field, `logo`, crops the site's own logo at each width (`<name>-logo-<width>.png`, with its box and a `tag#id.class` source, or `null` when the header has none), so design-review can show the real logo when the project has no logo file.
- **1.4.9** (2026-11-24): `capture.cjs` cuts a page taller than one part (4 widths, at most 1,600 px) into `-part-NN.png` shots at 1x, cropped from the full shot, with y ranges in `measures.json`; a full shot that would pass 16,384 px at 2x is taken at 1x (Astro run 3: a 31,354 px phone shot). Each mid-word break names its element, the heading above it, its y and its part, and small text, small tap targets and off-center rows carry a y. `--compare <earlier measures.json>` lists entries new since an earlier capture, matched by text, not by count. **Results first** (the maintainer's principle): nothing matters more than a result the user wants; save tokens by cutting waste, never by cutting a check, an option or a revise pass the result needs. Full text is rule 0 in `reference/house-rules.md`.
- **1.4.8** (2026-11-24): `capture.cjs` notes sections without headings: a `section`, `article`, `aside` or `role="region"` block at least 120 px tall and half the page wide, with text and no `h1`-`h6` inside, listed under "without a heading" as a note, not a failure (Astro run 2: AstroWind's proof strip and stats band). The evidence JSON carries `untitled` and `midWord`. A bare list of pages is taken as the pages file when `PROOFS_BASE_URL` gives the base, as under `with_server.py`.
- **1.4.7** (2026-11-24): `capture.cjs` scrolls each page to the bottom in 400 px steps and back before the shots and measures (`--no-scroll` skips it), so reveal-on-scroll sections and lazy images are in the full-page shot. New rows: `blank or hidden content` (a shot 90% one flat color below the first screen, or three or more in-flow blocks still at opacity 0) and `off-center columns` (a max-width section column not centered in its parent, or one whose left edge is more than 16 px from the columns above and below it). The mid-word check covers `<pre>` and `<code>` set to `word-break: break-all` or `overflow-wrap: anywhere`.
- **1.4.6** (2026-11-24): `capture.cjs` measures off-center rows: inside a `text-align: center` column, a row whose content gaps differ by more than 16 px (a flex or grid row, which text-align does not center, or a fixed-width block). Angular run 1's footer "Events" row sat at the left at 390 and nothing flagged it; it is now an `off-center rows` failure in the table, named with its gaps, and carried in the evidence. `with_server.py` removes its `.proofs/server.pid.lock` when it stops.
- **1.4.5** (2026-11-24): `capture.cjs` joins `base` and `path` with exactly one slash (SvelteKit run 1: `http://localhost:3311/` plus `/` made `//`, which SvelteKit serves as its 404 page). A page that answers HTTP 400 or above, or renders an error page ("Not Found"), is a FAILED shot: it is left out of the evidence, listed under `failures`, and the capture exits 6. A malformed pages file stops with one plain line saying what is wrong and where (exit 1), not a stack trace. The start line uses `--port`, with the flag per tool named.
- **1.4.4** (2026-11-23): A page wider than the phone is a finding, not a failed capture: an emulated phone that lays the page out wider than 390 is checked once more without phone emulation, and if that layout is 390 and the content runs past it, the capture records `sideways scroll: 17px, zoomed` with the widest element and keeps the phone's text and tap numbers. The "not trustworthy" exit 3 is kept for a browser that ignored the viewport. A line break at a hyphen, dash or slash no longer counts as a mid-word break.
- **1.4.3** (2026-11-23): Names the type check in the form the project uses (`npx vue-tsc --noEmit` for Vue, or the project's own `npm run type-check` or `npm run build`); the opt-in `--project` block now covers those and the Svelte, Astro and Angular checks.
- **1.4.2** (2026-11-23): `capture.cjs --sizes` also takes a desktop width from 400 to 2560 (for example `--sizes 390,1040,1440`), for a shot just above a breakpoint; with `--evidence` it is labeled with its width, like 1280.
- **1.4.1** (2026-11-23): House rule 2: never `ls` or Read `~/.cache/proofs-playwright` to see whether Playwright is installed (outside the project, so the call is refused); the capture and `--smoke` report a missing install themselves.

- **1.4.0** (2026-11-22): Opens its saved page with exactly `open .proofs/pages/<name>.html`, which the opt-in `--project` allow block pre-approves; if `open` is refused it prints the path instead of retrying. Adds house rule 4: use the capture helper's own size and overflow checks, never `file`, `magick`, `identify` or `sips`, and change files with Edit or Write, never `sed -i`.

- **1.3.1** (2026-11-22): `capture.cjs` launches the browser the way the review-page smoke check does (shared `launch.cjs`): Playwright's own browser if installed, else the installed Google Chrome, with no browser download, and `--disable-features=MacAppCodeSignClone` on every launch so a Mac run no longer leaves a 1.4 GB copy of Chrome in the temp folder. It also finds Playwright in `~/.cache/proofs-playwright`, and a missing Playwright prints the no-download install line.
- **1.3.0** (2026-11-22): Runs its scripts (`capture.cjs`) through `${CLAUDE_PLUGIN_ROOT}` and pre-approves them and reads of the plugin's own files, so a session no longer asks permission for each one.
- **1.2.0** (2026-11-19): Its review page sets `"skill": "visual-qa"`, so the header's pill names this skill rather than design-review, and fills `project.session`.
- **1.1.5** (2026-11-19): Says plainly that it needs the whole plugin, for anyone who copies one skill folder on its own.
- **1.1.4** (2026-11-18): Description trimmed to the trigger and how it differs from its nearest sibling; the detail it used to carry is in the body. No change in behavior.
- **1.1.3** (2026-11-18): Moved 'Where the page goes' to a shared reference file and the changelog to CHANGELOG.md; no change in behavior.
- **1.1.2** (2026-11-17): Copy buttons now fall back to a selectable text box when the clipboard is unavailable (as on a Wi-Fi-served page), and `wifi` mode is limited to a private network you trust. Framework-neutral wording for partial-page updates; invocation is `/proofs:visual-qa`.
- **1.1.1** (2026-11-16): New section "Where the page goes": a project can choose an artifact, a local file, or a file served on its own Wi-Fi.
- **1.1.0** (2026-11-16): Merged into proofs: generic, no project-specific steps.
